# JPE to Image Converter

Quick batch tool to convert `.jpe` images to `.png` or `.jpg`.

## Setup

```bash
pip install Pillow
```

## How to Use

1. Drop your `.jpe` files into `input_images/`.
2. Open terminal in the project root:
   ```bash
   python main.py
   ```
3. Type `png` or `jpg` when prompted and hit Enter.

Converted images will be saved in `converted/`.
